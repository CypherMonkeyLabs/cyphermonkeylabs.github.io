Thirteen labs

Ecosystem map

Thirteen labs, the sister technologies their own pages name, and the platform bridges those pages state. The drawing is SVG. It does not need WebGL. Choosing a node scrolls to its card. On a narrow screen the same nodes stack.

The flat diagram is the map. A 3D globe is an optional extra from the shared effects script. It stays off when that script is missing, when motion is reduced, or when WebGL is unavailable.

Glossary

Workforce management
Workforce management on this map means forecasting, scheduling, and adherence where a lab actually uses those words. Amazon Connect's README lists forecasting, capacity, and schedules, plus native and third-party WFM. Genesys Cloud's README covers workforce management and a forecasting chapter. Five9's README says its workforce calculator is Erlang C, not Five9's engine. Microsoft's ecosystem track names workforce management. NICE's published manifest has tracks named Workforce management and Workforce management on the day. Webex's published track list includes Workforce & Quality. The Zoom, Talkdesk and Avaya page has a track named WFM, recording, QM. The BA Lab diagram Sister technologies on the overview includes Workforce scheduling.
Call recording and quality management
Recording and quality management are the evaluation and capture notes a lab names. Amazon Connect's README puts Contact Lens, quality, and analytics in one chapter, and the ecosystem list includes recording and quality. SIP Universe track 14 names recording beside E911, and the README says recording stays at the protocol and policy level. Genesys's README covers quality management and speech and text analytics. Five9's published menu has a Quality item: evaluations, analytics wording, and claims left as claims. NICE's manifest has Quality and recording, and Quality and Interaction Analytics. Microsoft's ecosystem track names compliance recording and quality management. Webex's published track list includes Workforce & Quality, and the first-month plan names recording on the calling-security days. The Zoom page has a WFM, recording, QM track. The BA diagram includes Screen recording. The AI Lab contact-center track says to keep the model beside the queue, the recording, and the person who owns the call.
E911
E911 here is emergency calling as the labs describe it, not legal advice. SIP Universe track 14 is Toll fraud, E911, recording, and QoS. Amazon Connect's README lists US E911 for CCP agents. UC Lab has an Emergency calling track: prove location, ELIN or ERL, and the on-site notification. Microsoft's README includes an E911 discovery lab and emergency location. Genesys's README includes emergency calling. Five9's README lists E911 among the university pages. Webex's README names an ecosystem atlas that includes E911, and the published first-month plan names RedSky. CPaaS has an Emergency calling track. The Zoom, Talkdesk and Avaya page has an E911 and analytics track. Several of those pages say emergency notes are not legal advice.
Analytics
Analytics on this map is the reporting or speech-analytics work a lab names. Amazon Connect's published root menu has a Contact Lens chapter (transcripts, redaction, metrics, and evaluation forms). The README says the admin guide renamed Contact Lens to conversational analytics on 4 August 2026. Genesys's README covers speech and text analytics. Microsoft's mind-map list includes CQD and Power BI. Webex's README names analytics in the ecosystem atlas. Five9's Quality menu says evaluations, analytics wording, and claims left as claims. The Zoom page has an E911 and analytics track whose detail is location, and figures you confirm.
CRM
CRM on this map is a customer-record bridge a lab names. Amazon Connect's published menu has a CRM and CPaaS chapter. Microsoft's study order includes CRM and CTI (Dynamics 365 voice and Salesforce Voice). Genesys's README says Salesforce and Zendesk are the documented embeds and other CRMs stay on AppFoundry. Five9's README covers CRM adapters, and the published menu says named adapters and the CTI API, from the pages that opened. NICE's manifest has CRM integrations and CRM, CTI, and CPaaS. Webex's track list includes Flows, Integrations & Latest. The Zoom page has a CRM and AI bridges track. The BA diagram includes CRM profiles. The AI Lab ecosystem track says it maps CRM bridges.
AI agents
AI agents on this map means the agent, bot, or assist work a lab names. The AI Lab README is a course on prompts, agents, MCP, and a contact-center track. Amazon Connect's ecosystem list includes AI configuration, and the README names Lex and agent assist. Microsoft's sister-technologies list includes AI agents with a human escape. Genesys's README covers Genesys AI and bots. Five9's README names IVA and GenAI Studio. NICE's manifest has Enlighten, Autopilot, and summaries. Webex's published track list includes AI Agents & Voice. The Zoom page names Virtual Agent under Zoom Contact Center and has a CRM and AI bridges track. CPaaS has a Contact center and AI track. Python Lab's README includes models and agents among the lessons. The BA Lab README says the notes cover AI omni-channel work. Its sister-technologies diagram says IVR and bots, which is that diagram's phrase.

How a line got here

Every sister link and every bridge quotes a lab README or a published lab page fetched on 2026-10-19. A relationship that those pages do not state is not drawn. NICE's README marks Five9 and Webex Contact Center connectors as confirm, so those two are not bridges. The AI Lab README says other campuses are not linked from its pages, so this map does not add lab-to-lab lines for it.
