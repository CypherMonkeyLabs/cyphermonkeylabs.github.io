Ecosystem

Sister technologies are the ones this lab's README or published page names. A link to another lab is a bridge those pages state, or a page in that other lab that names this one. The ecosystem map shows the same links across all 13 labs.

  • Workforce management. README ecosystem atlas names WFM. Published track 09 is Workforce & Quality.
  • Call recording and quality management. README ecosystem atlas names recording. The published first-month plan names recording on days 25–30.
  • E911. README ecosystem atlas names E911. The published first-month plan names RedSky on the calling-security days.
  • Analytics. README ecosystem atlas names analytics.
  • CRM. Published track 08 is Flows, Integrations & Latest.
  • AI agents. Published track 10 is AI Agents & Voice. The README atlas names AI agents.
  • SIP Universe. SIP Universe README track 12 names Webex Calling Local Gateway and Cloud Connected PSTN.
  • Amazon Connect Lab. Amazon Connect's README says the study covers bridges from Webex, and the bridge track names Webex Contact Center.
  • Unified Communications Lab. UC Lab's study order goes to Webex Calling, and the CCaaS track names Webex CC. Webex's published track 11 is Platform Bridges: Unified CM, DI, and UCCX.
  • Microsoft Voice & Contact Center Lab. Microsoft's README links the Webex lab as a sister project and names Webex in the cross-platform bridge list.
  • Genesys Cloud Lab. Genesys's README says CUCM and Webex appear as a learning bridge with Cisco citations, not as a converter.
