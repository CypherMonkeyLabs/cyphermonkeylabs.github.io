What you learn

  • The README describes Teams voice and Microsoft contact-center study: a PowerShell console, a Direct Routing ladder, a 3D SBC mesh, labs, a fault catalog, and cited notes.
  • Its count table lists 20 tracks, 130 lessons, 25 labs, 668 quiz questions, 619 flashcards, and a 359-term glossary.
  • The ecosystem track names workforce management, compliance recording and quality management, E911, analytics and Power BI, CRM and screen pop, and AI agents with a human escape.
  • Cross-platform bridges named in the README: CUCM, Webex, UCCE, Genesys, and Amazon Connect.
  • Sister projects linked from the README: UC Lab, AI Lab, Webex, and the Gemini Gems gallery as a design reference.

Ecosystem

Sister technologies are the ones this lab's README or published page names. A link to another lab is a bridge those pages state, or a page in that other lab that names this one. The ecosystem map shows the same links across all 13 labs.

  • Workforce management. README ecosystem track and study-order step 6 name workforce management.
  • Call recording and quality management. README: compliance recording and quality management, including Teams compliance recording.
  • E911. README labs include E911 discovery and emergency location.
  • Analytics. README mind map includes CQD and Power BI.
  • CRM. README study order: CRM and CTI (Dynamics 365 voice and Salesforce Voice).
  • AI agents. README sister technologies: AI agents with a human escape.
  • SIP Universe. SIP Universe README track 12, Cloud voice and CCaaS SIP, names Teams Direct Routing.
  • Amazon Connect Lab. Amazon Connect's README integrations include Microsoft Teams. Microsoft's README bridge list names Amazon Connect.
  • Unified Communications Lab. UC Lab's README has a Webex Calling and Teams Phone track and a Teams Phone path of 67 sections. Microsoft's README links the UC Lab and names CUCM and UCCE among cross-platform bridges.
  • Genesys Cloud Lab. Microsoft's README lists Genesys among cross-platform bridges (CUCM, Webex, UCCE, Genesys, Amazon Connect).
  • Webex Lab. Microsoft's README links the Webex lab as a sister project and names Webex in the cross-platform bridge list.
  • AI Lab. Microsoft's README sister-project list links the AI Lab.
  • Gemini Gems gallery Microsoft's README lists it as a design reference.
