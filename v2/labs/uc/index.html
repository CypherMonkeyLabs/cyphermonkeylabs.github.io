What you learn

  • The README says the campus covers CUCM, CUBE, SIP, Webex Calling, Webex Contact Center, Teams Phone, UCCE, PCCE, CUIC, the main CCaaS platforms, E911, QoS, and troubleshooting.
  • The README counts 580 sections across 14 tracks. Four paths share them: Cisco Voice Core (314), Webex Calling (69), Teams Phone (67), and Contact Center Engineer (130).
  • The published page meta description says v21, with guided paths for those four names, and that it is offline after the shell is cached.
  • The proof habit in the README is leg, identifier, counter, and capture.

Ecosystem

Sister technologies are the ones this lab's README or published page names. A link to another lab is a bridge those pages state, or a page in that other lab that names this one. The ecosystem map shows the same links across all 13 labs.

  • E911. README Emergency calling track: prove location, ELIN or ERL, and the on-site notification.
  • Call recording and quality management. README Design notes track: read capacity, identity, recording, and failure domains. A lab named Record asks where the PSTN fork belongs.
  • SIP Universe. SIP Universe README track 15 is titled Ecosystem, certifications, and the UC bridge.
  • Amazon Connect Lab. Amazon Connect's README bridge track names CUCM, UCCX, and UCCE. UC Lab's CCaaS track names Connect.
  • Webex Lab. UC Lab's study order goes to Webex Calling, and the CCaaS track names Webex CC. Webex's published track 11 is Platform Bridges: Unified CM, DI, and UCCX.
  • Microsoft Voice & Contact Center Lab. UC Lab's README has a Webex Calling and Teams Phone track and a Teams Phone path of 67 sections. Microsoft's README links the UC Lab and names CUCM and UCCE among cross-platform bridges.
  • Genesys Cloud Lab. UC Lab's CCaaS track names Genesys. Genesys's README includes migration from Cisco UCCE / UCCX, and CUCM as a learning bridge.
  • NICE CXone Lab. UC Lab's CCaaS track names NICE.
  • Five9 Lab. UC Lab's CCaaS track names Five9. Five9's README calls the Cisco UCCX and UCCE material a teaching bridge.
  • AI Lab. The published UC campus page has a next-lab strip that names AI Lab.
  • Repository root The README points the round-2 course at the repository root index.
