Ecosystem

Sister technologies are the ones this lab's README or published page names. A link to another lab is a bridge those pages state, or a page in that other lab that names this one. The ecosystem map shows the same links across all 13 labs.

  • Workforce management. README covers workforce management and forecasting.
  • Call recording and quality management. README covers quality management.
  • E911. README includes emergency calling.
  • Analytics. README covers speech and text analytics.
  • CRM. README: Salesforce and Zendesk are the documented embeds. Other CRMs stay on AppFoundry.
  • AI agents. README covers Genesys AI and bots, and AI-agent bridges on the ecosystem page.
  • SIP Universe. SIP Universe README track 12 names Genesys BYOC.
  • Amazon Connect Lab. Amazon Connect's README says the study covers bridges from Genesys, and the bridge track names Genesys.
  • Unified Communications Lab. UC Lab's CCaaS track names Genesys. Genesys's README includes migration from Cisco UCCE / UCCX, and CUCM as a learning bridge.
  • Microsoft Voice & Contact Center Lab. Microsoft's README lists Genesys among cross-platform bridges (CUCM, Webex, UCCE, Genesys, Amazon Connect).
  • Webex Lab. Genesys's README says CUCM and Webex appear as a learning bridge with Cisco citations, not as a converter.
  • NICE CXone Lab. NICE's README says Genesys in that lab is the T-Lib / SIPREC recording page, not a named WFM connector. Five9 and Webex Contact Center are marked confirm: no opened page named them, so this map does not draw those two as bridges.
  • Published landing page The README gives this as the canonical landing URL. The open button uses the campus URL from the lab registry.
