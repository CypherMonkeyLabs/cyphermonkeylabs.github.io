# Front door (cinematic home page)

`index.html` is generated by hand-editable static HTML. Pieces:

- `css/cinema.css` – theme (own palette, exempt from the tokens.css hex rule).
- `js/cinema/main.js` – menu, reveal, card tilt, sound toggle, lazy hero.
- `js/cinema/hero.js` – three.js hero (vendored `/vendor/three`), lazy, paused off screen, skipped for reduced motion, save-data, or no WebGL. The CSS 3D orbit in the HTML is the fallback.
- `js/cinema/dragbot.js` – draggable guide monkey that answers from `/data/labs.json`.
- `js/cinema/audio.js` – optional ambient pad, off by default, created only after a click.
- `assets/trailer/trailer-src.html` – deterministic canvas animation (`drawAt(t)`); `trailer.mp4` and `poster.jpg` were rendered from it with Playwright + ffmpeg (12 s, silent, under 1 MB). The video never autoplays.
- Contact form: unchanged `js/trust/contact.js` (Turnstile loads lazily near the form).

Link rule: anchors may point only to this site, `github.com/CypherMonkeyLabs`, `github.com/cipher0x9`, and `linktr.ee/cyphermonkey`. `node .github/scripts/check-frontdoor-links.mjs` enforces it for `index.html`.
