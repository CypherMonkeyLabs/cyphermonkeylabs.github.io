Privacy

This page describes the studio website only. Each lab you open has its own pages and its own practices.

What this site is

Cypher Monkey Labs is a set of static files. This website does not run an account system, and it does not add analytics, ads, or tracking pixels.

What we don't collect here

There are no cookies and no sign-in. The site does not sell personal information. Quiz totals and other unpublished counts are left off the page until a lab publishes them.

What stays on your device

If you change the color theme, sound, motion, map view, or greeting language, that choice is saved in this browser's local storage. It stays on your device. Clearing site data for this address removes it.

Sound

Sound is off until you turn it on. If you turn it on, your browser speaks the greeting. Some browsers do this on the device. Some may use an online voice that the browser chooses. This site does not receive that audio and does not send the greeting to a server of ours.

Hosting logs

Whoever hosts these files can see ordinary request logs, such as an IP address, the way any web host does. This project does not add its own logging on top.

Links you choose

Opening a lab, a GitHub page, a social page if one is added later, or email leaves this site. Those places have their own privacy practices. This site does not embed their trackers.

Email

The contact form opens your email app to research@cyphermonkeylabs.com unless a form address is set in the site data. When that address is set, your browser sends the name, email, topic, and message there. This website does not keep a copy. A takedown note uses the same form with the topic set to a concern.
